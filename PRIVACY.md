# Privacy Policy

**Last Updated:** November 2025

## Simple Summary

This extension processes Google Docs locally in your browser. No data collected, transmitted, or stored externally.

## What We Access

- **Google Docs content** - Read-only access when you click "Copy for LLM"
- **Document images** - To include in markdown output
- **Your preferences** - Stored locally in Chrome (e.g., heading style)

## What We DON'T Do

- ❌ No external servers or databases
- ❌ No tracking or analytics
- ❌ No data collection or storage
- ❌ No third-party sharing
- ❌ No browsing history access

## How It Works

1. You click "Copy for LLM" on a Google Doc
2. Extension reads document via Google APIs
3. Converts to markdown **locally in your browser**
4. Copies to clipboard or downloads file
5. Nothing sent anywhere

## Permissions Explained

- `identity` - OAuth login with Google
- `storage` - Save your preferences locally
- `clipboardWrite` - Copy markdown to clipboard
- `downloads` - Download markdown files
- `docs.google.com` - Inject copy button
- `googleapis.com` - Fetch document content
- `googleusercontent.com` - Access document images

## Your Control

- Revoke access anytime: [Google Account Permissions](https://myaccount.google.com/permissions)
- Uninstall extension: Chrome settings → Extensions
- View source code: [GitHub](https://github.com/shubgaur/better-google-docs-copy)

## Compliance

Complies with Chrome Web Store policies, Google API User Data Policy, and GDPR.
